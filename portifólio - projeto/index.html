PROJETO 01

Design de Loja Virtual — Le Petit Cake

Projeto de design desenvolvido em dupla no Figma, com a criação de uma proposta visual para a confeitaria fictícia Le Petit Cake. A atividade teve como objetivo explorar conceitos de design, organização dos elementos visuais, escolha de cores e criação de uma identidade visual para a marca.

☾

PROJETO 02

Página de Apresentação de Equipe

Desenvolvimento de uma página para apresentar a equipe fictícia da AppWave Solutions, com cartões contendo fotos, nomes, cargos e descrições dos profissionais. O projeto foi desenvolvido com HTML e CSS, permitindo praticar a organização de elementos na página e a criação de cartões para apresentar informações de forma visual e organizada.

✧

PROJETO 03

Página Web com Variáveis CSS

Criação de uma página para o restaurante fictício Bella Massa, com informações sobre o estabelecimento, imagem e botões de navegação. O projeto foi desenvolvido com HTML e CSS, com foco no uso de variáveis CSS para personalizar e organizar os estilos da página.
